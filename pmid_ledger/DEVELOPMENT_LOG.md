### 職場Macでの再開手順

まず作業中の変更を確認し、同じ専用ブランチを取得する。変更があって切り替えやfast-forwardができない場合は、無断でreset・stash・上書きしない。

```bash
git status --short --branch
git fetch origin
git switch codex/ledger-candidate-review
git pull --ff-only origin codex/ledger-candidate-review
```

`git switch`は既存ローカルブランチを使う。ローカルに同名がなく、`origin`だけにある場合はGitの自動追跡作成を利用できる。main側の取り込みは履歴・差分を確認して別途実施し、force pushしない。

次に本ログ、[README](README.md)、`gas/Code.gs`、`gas/Index.html`、`tests/`を確認する。ローカルでの再現は次のコマンドを使用する。

```bash
node --test pmid_ledger/tests/*.test.mjs
PREVIEW_PROFILE=1 node pmid_ledger/preview.mjs
```

プレビューは架空データ・メモリ保存のみで、Googleの待ち時間を再現するものではない。Python側を変更する場合は、既存環境または仮想環境でREADME記載のPythonテストも実行する。

`ledger_private/`、Google認証JSON、`~/.clasprc.json`、接続ID・URLを含むローカル設定はGit対象外で、pullしても別Macには移らない。本ログには再開判断に必要な集計値を転記済みで、構成比較の計画や架空データ試作は生データなしで進められる。実サービスを再確認する場合だけ、職場Macの本人Googleアカウントと既存プロジェクトへの接続を確認する。接続情報・認証情報をリポジトリへ追加しない。

GASを再変更する場合は既存の同期先を確認し、隔離したフォルダーへpullして差分を照合する。既存リモートのサーバーコード名は`コード.js`で、Git側の`gas/Code.gs`と対応する。`clasp push`はソース同期で、deploymentは常にユーザーが手動で行う。公開範囲・実行者・スコープを無断で変更しない。
